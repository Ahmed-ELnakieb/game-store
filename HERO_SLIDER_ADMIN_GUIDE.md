# Hero Slider Admin Panel Guide

## How to Edit Hero Slider Content in Admin Panel

### Step 1: Login to Admin Panel
- Go to: `your-domain.com/admin`
- Login with your admin credentials

### Step 2: Navigate to Hero Slider Management
- Go to: **Frontend Management** → **Manage Content** → **Dark Hero**
- Or directly visit: `your-domain.com/admin/frontend/content/dark_hero`

### Step 3: Edit Slider Items
You'll see 2 slider items listed. Click the **Edit** button on any slider to modify:

#### Available Fields:
1. **Title** - Main heading (e.g., "PUBG Mobile Hacks 2025")
2. **Sub Title** - Promotional text (e.g., "50% Off Premium Aimbot & ESP")
3. **Description** - Detailed description of the offer
4. **Kew Text** - Button text (e.g., "Get PUBG Hacks", "Buy COD Hacks")
5. **Button Link** - Where the button redirects (e.g., `/cards`, `/products`)
6. **Box Type** - Visual style (dark-moderate-blue-box, very-light-blue-box)
7. **Background Image** - Upload slider background image

### Step 4: Change Button Destination
To change where the "Get PUBG Hacks" or "Buy COD Hacks" button redirects:

1. Find the **Button Link** field
2. Enter your desired URL:
   - `/cards` - Products/Cards page
   - `/products` - Products listing
   - `/contact` - Contact page
   - Or any custom URL

### Step 5: Save Changes
- Click **Save changes** button
- The slider will update immediately on the homepage
